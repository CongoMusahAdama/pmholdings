# Nana Quasi Weisa (PM) — Portfolio Website

A high-end, multi-page portfolio site for Nana Quasi Weisa (PM): entertainment consultant, philanthropist, fashion entrepreneur, and model.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Framer Motion
- React Helmet Async

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Pages

| Route | Page |

## Customization

- Replace placeholder images (`PlaceholderImage` labels) with real photography
- Update stats, emails, and social links in `src/data/ventures.ts`
- Wire the contact form to your preferred backend / form service
